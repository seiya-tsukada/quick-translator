# QuickLens Translator

Translate text you select on a web page — from the right-click menu, a keyboard shortcut (Alt+T) or the toolbar popup.

- Default engine: Chrome's built-in on-device translation (Translator API / Language Detector API). Free, no key, the text stays on your device. Requires desktop Chrome 138 or later.
- Optional: your own OpenAI or DeepL API key. The text is then sent directly to that provider.
- The developer runs no server and collects no data. API keys are stored only on this device.

See the repository README and `docs/privacy-policy.md` for details.
